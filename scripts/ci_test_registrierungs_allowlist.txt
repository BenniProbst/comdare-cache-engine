# einen optionalen Fremdbaum ist ohne diesen Baum legitim abwesend. Was NICHT legitim
# ist: dass diese Abwesenheit unbemerkt bleibt.
#
# FORMAT je Zeile, drei Felder, '|'-getrennt:
#
#   <test-quelldatei> | <gegenstand-der-fehlen-muss> | <begruendung>
#
# Feld 2 ist der Kern und der Grund, warum diese Liste kein Freibrief ist: es nennt
# einen GEGENSTAND auf der Platte, dessen ABWESENHEIT die Ausnahme traegt. Die Wache
# prueft ihn bei jedem Lauf nach. Existiert die Datei wieder, ist die Ausnahme
# ERLOSCHEN und die Zeile wird ROT -- ohne dass jemand diese Liste anfassen muss.
# Eine Allowlist ohne diese Gegenprobe waere eine Freistellung mit unbegrenzter
# Laufzeit; genau daran sind die vier unregistrierten Dateien 14 bzw. 68 Tage lang
# nicht aufgefallen.
#
# Feld 2 leer lassen ist zulaessig, aber die schwaechste Form: dann ist die Ausnahme
# nur ein Satz und laeuft nie ab. Wer das tut, sollte in Feld 3 sagen, warum es
# keinen pruefbaren Gegenstand gibt.
#
