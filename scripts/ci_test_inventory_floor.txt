# JEDE ihrer Zahlen aus dem Baum, den sie gerade prueft. Schrumpft der Baum,

# gemessene Baum nicht beeinflussen kann: sie stammt aus einem frueher bewusst
# abgenommenen Zustand und aendert sich nur durch einen Menschen in einem eigenen,
# im Diff sichtbaren Commit.
#
# DIE WACHE SCHREIBT DIESE DATEI NIEMALS SELBST. Eine Untergrenze, die sich beim
# Unterschreiten automatisch nachfuehrt, ist keine Untergrenze, sondern ein
# Protokoll des Verfalls. Waechst die Testzahl, sagt die Wache das ausdruecklich
# an und die Zahl hier gehoert dann von Hand nachgezogen -- als eigener Commit,
# damit die Aenderung im Diff auffaellt und jemand sie absichtlich verantwortet.
